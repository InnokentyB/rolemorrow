# Judge access and walkthrough

## Entry point

Use the repository's downloadable Docker test build. Follow README's two startup commands and open http://127.0.0.1:3028/. No account, credentials, real mailbox, API key or payment is needed. This gives a separate local fictional workspace matching the video's scenario. It does not grant access to the owner's hosted account or claim source/deployment parity with the independently operated hosted service.

## Five-minute scenario

1. Click **Use fictional example**. Inspect the confirmed facts and ProductManager goal. These are synthetic examples, not a real applicant's CV.
2. Click **Check selected companies**. These results use deterministic demo providers; they are not current real job listings or actual provider calls.
3. Open **Show job details**, then **Review evidence**. Compare the requirement with its profile quotation. Review unconfirmed role level/location conditions. A supported skill does not establish seniority or work eligibility.
4. **Save job**. In **Saved jobs**, open **Your decision & next action**, enter a fictional next action and **Save decision**. Return after a check or refresh to see the saved decision retained.
5. In **Applications**, enter fictional CV version/text, cover letter and screening answers. **Save application packet**, inspect saved revisions or export. These are manually entered demonstration materials, not a guaranteed accepted AI result.
6. Explore Inbox's empty/manual/simulated paths only if clearly labelled. Do not mistake a simulated invitation for a real reply. The video discusses dated controlled mail evidence separately; this default build sends no emails.
